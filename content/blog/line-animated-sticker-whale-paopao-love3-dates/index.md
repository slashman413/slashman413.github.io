## How we built it

1. **Same character, new poses:** FLUX schnell fp8 + whimsical-storybook LoRA, run locally on an NVIDIA GB10 with the same seed as volume 2, so Paopao looks the same across the series.
2. **APNG pipeline:** Python cut-out, white sticker rim, procedural motion and effects, 3-second loops within LINE's 320×270 / 300 KB limits.
