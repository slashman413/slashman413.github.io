<h2>1. Coursera — 學術派、證照最強</h2>

<p>Coursera 由史丹佛大學教授創立，與全球 250 多所大學和企業合作。其 <strong>AI 相關課程</strong>主要包括：</p>

<ul>
  <li><strong>Deep Learning Specialization（吳恩達）</strong>：AI 領域公認最經典的系列課程，涵蓋神經網路、CNN、RNN、Transformer 等核心概念</li>
  <li><strong>AI for Everyone（吳恩達）</strong>：適合非技術背景的管理者，用通俗語言解釋 AI 的商業應用</li>
  <li><strong>Generative AI with Large Language Models（ deeplearning.ai ）</strong>：專注於 LLM 的 Prompt Engineering、RAG、AI 應用開發</li>
  <li><strong>Machine Learning Specialization（Andrew Ng）</strong>：机器学习入門經典</li>
</ul>

<p><strong>優點：</strong></p>
<ul>
  <li>證照認可度高，許多大企業在招聘時直接承認 Coursera 證書</li>
  <li>課程品質穩定，由頂尖大學和企業開發</li>
  <li>每月 $39–$99 的訂閱制可無限學習所有課程（但證書需額外付費）</li>
  <li>有財務援助計劃（Financial Aid），經濟困難者可申請免費學習</li>
</ul>

<p><strong>缺點：</strong></p>
<ul>
  <li>偏重理論，實戰項目較少</li>
  <li>課程更新速度較慢——有些 Deep Learning 課程的 LLM 章節仍停留在 2024 年的 GPT-4</li>
  <li>作業評閱多為同儕評量（peer review），不夠精確</li>
  <li>中文資源相對較少，建議具備一定英文能力</li>
</ul>

<p><strong>我的評價：</strong>如果你是「學術導向」或需要一個<strong>「硬碰硬的證書」放在履歷上</strong>，Coursera 無疑是最佳選擇。但如果你追求的是「今天上完明天就能用」的實戰技能，它的學習曲線會比較長。</p>

<p><strong>推薦課程：</strong>「Generative AI with Large Language Models」是目前 Coursera 上最接近 2026 年產業需求的 AI 課程。內容涵蓋了 Prompt Engineering 的最佳實踐、RAG 系統的設計、以及 Agent 架構的實作。</p>

<h2>2. Udemy — 便宜好用，但要篩</h2>

<p>Udemy 是「市場型」線上學習平台，任何人都可以上傳課程。這意味著品質參差不齊，但也因此覆蓋了幾乎所有你能想到的主題。</p>

<p>在 <strong>Udemy 上找優質 AI 課程</strong>的技巧：</p>

<ul>
  <li><strong>看評分 4.5 以上、評論 500 則以上</strong>：這是最基本的篩選條件</li>
  <li><strong>看更新日期</strong>：AI 領域變遷極快，超過一年的課程可能已經過時</li>
  <li><strong>看預覽影片</strong>：講者的表達風格很重要，不合脾氣的話很難堅持學完</li>
  <li><strong>關注熱門講師</strong>：Dr. Angela Yu、Jose Portilla、Laurent LDo 等講者的課程品質相對穩定</li>
</ul>

<p><strong>推薦課程：</strong></p>
<ul>
  <li><strong>「100 Days of Code: The Complete Python Pro Bootcamp」</strong>：適合從零開始學 Python，為後續 AI 課程打基礎</li>
  <li><strong>「Complete Generative AI with LangChain Bootcamp」</strong>：涵蓋 RAG、Agent、LangChain 框架等實戰技能</li>
  <li><strong>「ChatGPT Prompt Engineering for Developers」</strong>：Deeplearning.ai 與 Anthropic 合作課程，由 Andrej Karpathy 參與設計</li>
</ul>

<p><strong>優點：</strong></p>
<ul>
  <li>價格便宜（常有 $10–$20 的促銷）</li>
  <li>一次性購買、永久存取</li>
  <li>涵蓋從入門到進階的所有層級</li>
  <li>學習進度追蹤和問答區互動</li>
</ul>

<p><strong>缺點：</strong></p>
<ul>
  <li>品質波動極大，需要花時間篩選</li>
  <li>沒有官方證照，學完後只能拿到 Udemy 的完成證書</li>
  <li>有些課程為了趕進度，內容深度不夠</li>
  <li>課程更新完全取決於講師——很多熱門課程內容停留在 2023 年</li>
</ul>

<p><strong>我的評價：</strong>Udemy 最適合<strong>「預算有限的自學者」</strong>。但你要做好心理準備：花時間篩選課程、預覽影片、查看最新評論——這些功夫不能省。我建議搭配 <a href="https://slashmantools.us/blog/prompt-engineering-checklist-2026/">我的提示詞工程清單</a> 來實戰練習，這樣能最大化 Udemy 課程的學習效果。</p>

<h2>3. ChatGPT 內建教學 — 免費但局限</h2>

<p>OpenAI 在 2025 年底推出了 ChatGPT 的<strong>內建學習功能（AI Course 功能）</strong>，讓使用者可以直接在 ChatGPT 介面中學習各種主題。這對於想要<strong>「用 ChatGPT 學習 ChatGPT」</strong>的人來說，聽起來很美好。</p>

<p><strong>內建教學的優點：</strong></p>
<ul>
  <li><strong>完全免費</strong>（ChatGPT Plus 訂閱者享有完整功能）</li>
  <li>互動式教學，學完可以立即實戰</li>
  <li>即時反饋，不懂可以直接問 AI</li>
  <li>內容涵蓋 Prompt Engineering、API 使用、多模型比較等實用主題</li>
</ul>

<p><strong>但它的問題也很明顯：</strong></p>
<ul>
  <li><strong>缺乏系統性</strong>：每個教學模組獨立運作，沒有完整的學習路徑設計</li>
  <li><strong>深度有限</strong>：多數內容停留在「怎麼用」的層次，很少深入「為什麼這麼設計」</li>
  <li><strong>沒有進度追蹤</strong>：學了什麼、還缺什麼，完全靠自己記憶</li>
  <li><strong>更新不可控</strong>：OpenAI 決定更新節奏，你無法要求特定主題的課程</li>
</ul>

<p><strong>我的評價：</strong>ChatGPT 內建教學是很好<strong>「入門工具」</strong>——你可以花 30 分鐘快速了解 ChatGPT 的基本能力。但如果你想系統性地掌握 AI 實戰技能，它更像是一本「速讀手册」而不是「教科書」。</p>

<p>我建議把 ChatGPT 內建教學作為<strong>「試水溫」</strong>的階段：先學完它，確定自己有興趣再投入正式課程。</p>

<h2>4. Google AI Skills — 被低估的免費資源</h2>

<p>Google 的 <strong>AI Skills 平台</strong>提供了一系列免費的 AI 相關學習資源，涵蓋 Google Cloud AI 工具、TensorFlow 教程、Gemini API 使用指南等。</p>

<p><strong>適合的族群：</strong></p>
<ul>
  <li>對 <a href="https://slashmantools.us/blog/ai-agent-automation-guide/">AI Agent 自動化</a> 感興趣的開發者</li>
  <li>使用或打算使用 Google Cloud 生態的團隊</li>
  <li>希望了解 Google Gemini 系列模型的學習者</li>
</ul>

<p><strong>優點：</strong></p>
<ul>
  <li>完全免費，部分課程提供 Google Cloud 額度</li>
  <li>內容由 Google 官方工程師開發，權威性高</li>
  <li>結合 Google Cloud 實戰環境，邊學邊做</li>
</ul>

<p><strong>缺點：</strong></p>
<ul>
  <li>對 Google 生態依賴度高，其他平台的工具較少涉及</li>
  <li>部分課程需要一定的程式基礎</li>
  <li>互動性較弱，主要是閱讀和作業</li>
</ul>

<p><strong>我的評價：</strong>Google AI Skills 是一個<strong>「被低估的寶庫」</strong>。它的不足是廣度較窄，但深度不錯。建議與 Coursera 或 Udemy 的課程搭配使用，作為補充教材。</p>

<h2>我的實戰建議：無論選哪個平台，請記住這三件事</h2>

<p>不管你在哪個平台學 AI，以下三件事會決定你的學習效果：</p>

<p><strong>第一：不要只做「被動學習」</strong></p>

<p>看 10 小時影片不如實際操作 1 小時。每學一個概念，立刻用 ChatGPT 或 Claude 實戰練習。例如：學完 Prompt Engineering 理論後，試著用不同的提示詞模板來完成你手邊的工作任務。這才是把知識變技能的唯一方法。</p>

<p><strong>第二：保持課程的「新鮮度」</strong></p>
