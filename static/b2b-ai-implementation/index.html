Common technical and commercial questions

No. During Days 3–11 we build and validate against deterministic mock handlers and sandbox credentials. Production API keys are injected into your own secret manager or CI environment during Day 12–14 cutover—our team never stores your production customer data.

What happens if our workflow turns out to be larger than one $2,500 sprint?

We identify scope boundaries during the free 20-minute scoping call and Day 1–2 audit before building. If your process spans multiple independent workflows, we isolate the highest-ROI slice that fits cleanly inside the 14-day / $2,500 fixed sprint so you see working production output before committing to a second sprint.

Which LLM providers and runtime stacks do you deploy on?

We deploy clean Python 3.11+ or Node.js/TypeScript services (Docker-ready for AWS, GCP, Fly.io, Railway, Render, or self-hosted Linux/DGX boxes). The hexagonal adapter layer works with OpenAI, Anthropic, Google Gemini, OpenRouter, or self-hosted OpenAI-compatible local models (vLLM / Ollama).
